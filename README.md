# Decoding the 2026 Tamil Nadu Assembly Election

A storytelling-first data analytics project for the Codebasics Resume Project Challenge.

**Status:** 🚧 In progress

## What this project does
Turns 234 constituencies of raw Election Commission of India (ECI) data into a TV-ready data story for the fictional client "AtliQ Media".

## Data sources
- Election Commission of India — [results.eci.gov.in](https://results.eci.gov.in/ResultAcGenMay2026)
- Trivedi Centre for Political Data, Ashoka University (2021 cleaned data)

## Reproduce
```bash
conda env create -f environment.yml
conda activate tn-election
jupyter notebook
```

## Disclaimer
This is a non-partisan data analysis exercise. No party, leader, community, region, or religion is endorsed or criticised. All conclusions are sourced from publicly available ECI data only.
